# The test is 99% accurate. You tested positive. Should you worry?

A screening test for a rare condition comes back positive. The leaflet says the test
is 99% accurate: it catches 99 of every 100 people who have the condition, and clears
99 of every 100 who don't. So what is the chance you actually have it?

Most people, and in surveys most doctors, say about 99%. Make your own guess before
reading on.

```bib
let guess = 0
let shown = state("reveal", false)
row {
  card("Your guess", subtitle: "1 in 100 people tested have the condition") {
    guess = slider("Chance I have it (%)", 0, 100, value: 90, step: 1)
    row(fit: true) {
      if button("Show me", style: primary, disabled: shown).clicked { set("reveal", true) }
      if button("Hide", style: ghost, disabled: !shown).clicked { set("reveal", false) }
    }
  }
  card("The answer", tone: shown ? accent : neutral) {
    if shown {
      stat("Chance you have it", 50, unit: "%", tone: accent)
      text(abs(guess - 50) <= 5 ? "Spot on. Most people are far too high." : guess > 50 ? "You guessed {guess}%: {guess - 50} points too high, like most people." : "You guessed {guess}%: too low, which is rarer.", size: sm, color: muted)
    } else {
      text("A positive result on a 99% accurate test, for a condition 1 in 100 people have.", color: muted)
    }
  }
}
```

A coin flip. Not because the test is bad, but because the condition is rare. The rest
of this page shows why, with a thousand people you can count.

###### Part one

## A thousand people

Below are 1,000 people who take the test. Set how common the condition is (the
**prevalence**, also called the base rate) and how good the test is. The
**sensitivity** is the share of sick people it catches; the **specificity** is the
share of healthy people it correctly clears.

```bib
let prev = 0
let sens = 0
let spec = 0
row {
  card("The population") {
    prev = slider("Prevalence (%)", 0.1, 50, value: 1, step: 0.1) / 100
  }
  card("The test") {
    sens = slider("Sensitivity (%)", 50, 100, value: 99, step: 0.5) / 100
    spec = slider("Specificity (%)", 80, 99.9, value: 99, step: 0.1) / 100
  }
}

// whole people, out of 1,000
let sick = round(1000 * prev)
let TP = round(sick * sens)
let FN = sick - TP
let FP = round((1000 - sick) * (1 - spec))
let TN = 1000 - sick - FP
// the exact probability, not rounded to whole people
let post = prev * sens / (prev * sens + (1 - prev) * (1 - spec))

let byResult = toggle("Line them up by test result", value: false)
let order = byResult ? [["TP", TP], ["FP", FP], ["FN", FN], ["TN", TN]] : [["TP", TP], ["FN", FN], ["FP", FP], ["TN", TN]]
let edges = order.reduce((acc, o) => [...acc, acc[acc.length - 1] + o[1]], [0])
let tone = {TP: danger, FN: accent, FP: warning, TN: fade(muted, 0.28)}
let kindOf = i => i < edges[1] ? order[0][0] : i < edges[2] ? order[1][0] : i < edges[3] ? order[2][0] : order[3][0]

box(width: fill, height: 540, radius: 12, border: 1, background: "raised") {
  layer {
    // w is the box's width as the layer sees it: + − × ÷ by numbers only, so the cell height is worked out from the fixed 540
    let cw = (w - 24) / 40
    let ch = (540 - 24) / 25
    let r = ch * 0.19
    for i in data.people {
      let x = 12 + (i % 40) * cw + cw / 2
      let y = 12 + floor(i / 40) * ch
      let c = tone[kindOf(i)]
      circle(x, y + ch * 0.28, r, fill: c)
      rect(x - r * 1.5, y + ch * 0.26 + r * 1.25, r * 3, ch * 0.42, fill: c, radius: r)
    }
  }
}
row(fit: true) {
  badge("{TP} sick, test positive", tone: danger)
  badge("{FN} sick, missed", tone: accent)
  badge("{FP} healthy, false alarm", tone: warning)
  badge("{TN} healthy, cleared", tone: muted)
}

grid(columns: 3) {
  stat("Positive results", TP + FP)
  stat("…of whom are sick", TP, tone: danger)
  stat("Chance a positive is sick", round(post * 100, 1), unit: "%", tone: post < 0.5 ? warning : accent)
}
```

Look at the people with a positive result: the red ones and the yellow ones. When the
condition is rare, the healthy crowd is so large that even a tiny error rate among
them produces as many false alarms as there are real cases. Turn on *Line them up by
test result* and count.

###### Part two

## The natural-frequency tree

The same thousand people, split twice: first by whether they are sick, then by what
the test says. Only the two "test positive" branches matter to someone holding a
positive result.

```bib
// the tree in one layer: node k sits at a fraction of the width, links are as thick as their crowd
let nodes = [
  {f: 0.5, y: 40, n: 1000, t: "people tested", tone: ink},
  {f: 0.25, y: 150, n: sick, t: "have it ({round(prev * 100, 1)}%)", tone: danger},
  {f: 0.75, y: 150, n: 1000 - sick, t: "don't ({round(100 - prev * 100, 1)}%)", tone: ink},
  {f: 0.125, y: 260, n: TP, t: "test positive", tone: danger, hot: true},
  {f: 0.375, y: 260, n: FN, t: "test negative", tone: accent},
  {f: 0.625, y: 260, n: FP, t: "test positive", tone: warning, hot: true},
  {f: 0.875, y: 260, n: TN, t: "test negative", tone: muted},
]
let links = [[0, 1], [0, 2], [1, 3], [1, 4], [2, 5], [2, 6]]

box(width: fill, height: 300, radius: 12, border: 1, background: "raised") {
  layer {
    for l in links {
      let a = nodes[l[0]]
      let b = nodes[l[1]]
      line(w * a.f, a.y + 26, w * b.f, b.y - 26, color: b.hot ? fade(b.tone, 0.55) : fade(muted, 0.3), width: 1.5 + 22 * Math.sqrt(b.n / 1000))
    }
    for nd in nodes {
      rect(w * nd.f - 92, nd.y - 26, 184, 52, fill: nd.hot ? fade(nd.tone, 0.12) : "surface", color: nd.hot ? nd.tone : border, width: nd.hot ? 2.5 : 1, radius: 12)
      label(w * nd.f, nd.y - 8, str(nd.n), size: 20, color: nd.tone, align: center)
      label(w * nd.f, nd.y + 13, nd.t, size: 12, color: muted, align: center)
    }
  }
}

box(gap: 6, padding: [12, 16], radius: 12, background: fade(accent, 0.08)) {
  text("P(sick | positive) = sick positives / all positives", face: mono, size: sm, color: muted)
  text("= {TP} / ({TP} + {FP}) ≈ {round(post * 100, 1)}%", face: mono, size: lg, weight: bold, color: accent)
  text("Bayes' theorem says the same with probabilities: P(sick | +) = P(+ | sick)·P(sick) / P(+) = {round(sens, 3)} × {round(prev, 4)} / ({round(sens, 3)} × {round(prev, 4)} + {round(1 - spec, 4)} × {round(1 - prev, 4)})", size: sm, color: muted)
}
```

This is all of Bayes' theorem: a probability after the evidence is the share of the
people *with that evidence* who are sick. Counting people instead of multiplying
percentages is the trick: researchers who give doctors the question as natural
frequencies ("10 out of 1,000") get far more right answers than with percentages.

###### Part three

## Test again

You have one positive result, and the chance of being sick that Part two worked out
(50% at the starting settings). A second, independent test starts from there: **today's posterior is tomorrow's prior.** Add results one at a time and
watch the probability move.

```bib
let seq = state("results", [])
row(fit: true) {
  if button("Another positive", style: primary, disabled: seq.length >= 5).clicked { set("results", [...seq, "+"]) }
  if button("A negative", disabled: seq.length >= 5).clicked { set("results", [...seq, "−"]) }
  if button("Start over", style: ghost, disabled: seq.length == 0).clicked { set("results", []) }
}
let update = (p, r) => r == "+" ? sens * p / (sens * p + (1 - spec) * (1 - p)) : (1 - sens) * p / ((1 - sens) * p + spec * (1 - p))
let all = ["+", ...seq]
let chainP = all.reduce((acc, r) => [...acc, update(acc[acc.length - 1], r)], [prev])

box(width: fill, gap: 10, padding: 18, radius: 12, border: 1, background: "raised") {
  for p in chainP {
    box(dir: "row", gap: 12, align: center) {
      box(width: 150) { text(index == 0 ? "before any test" : "after test {index} ({all[index - 1]})", size: sm, color: muted) }
      box(width: fill, padding: [4, 0, 0, 0]) {
        box(width: fill, height: 14, radius: 7, background: fade(muted, 0.12)) {
          layer { rect(0, 0, 3 + (w - 3) * p, h, fill: index == 0 ? muted : p >= 0.5 ? danger : accent, radius: 7) }
        }
      }
      box(width: 80) { text("{p < 0.001 ? "<0.1" : round(p * 100, 1)}%", size: sm, face: mono, weight: bold) }
    }
  }
}
text("Each positive multiplies the odds by {round(sens / (1 - spec), 1)}, each negative by {round((1 - sens) / spec, 4)}.", size: sm, face: mono, color: accent)
text(chainP[chainP.length - 1] > 0.95 ? "Two or three positives in a row make it close to certain." : seq.includes("−") ? "A single negative pulls the probability most of the way back down." : "Press Another positive and see how fast it climbs.", size: sm, color: muted)
```

Each positive multiplies the *odds* of being sick by the same factor, the likelihood
ratio sensitivity / (1 − specificity), which is 99 for a 99/99 test. One
positive takes 1 : 99 odds to about 1 : 1; a second takes 1 : 1 to about 99 : 1. This
is why a positive screening result is followed by a different, confirmatory test
rather than a diagnosis. (It only works if the two tests' errors are independent: the
same test repeated on a person whose body fools it will be fooled twice.)

###### Part four

## It depends on who is tested

The same test means different things in different crowds. Screening everyone, the
prevalence is low and positives are often false; testing people with symptoms, the
prevalence is high and a positive is convincing. The chart sweeps the prevalence from
1 in 10,000 to everyone, for the test you set above.

```bib
let lx = k => -4 + k * 0.05
let ppvAt = p => p * sens / (p * sens + (1 - p) * (1 - spec))
let fnAt = p => p * (1 - sens) / (p * (1 - sens) + (1 - p) * spec)
let ppvs = data.sweep.map(k => ppvAt(Math.pow(10, lx(k))))
let fns = data.sweep.map(k => fnAt(Math.pow(10, lx(k))))
let negAfter = fnAt(prev)

fn poly(xs, ys, color: accent, width: 2) {
  for x in xs where index > 0 { line(xs[index - 1], ys[index - 1], x, ys[index], color: color, width: width) }
}

box(width: fill, height: 300, radius: 12, border: 1, background: "raised") {
  layer {
    let X = l => 58 + (w - 74) * (l + 4) / 4
    let Y = v => 14 + (h - 48) * (1 - v)
    for g in [0, 0.25, 0.5, 0.75, 1] {
      line(58, Y(g), w - 16, Y(g), color: fade(muted, 0.15))
      label(50, Y(g), "{round(g * 100)}%", size: 11, color: muted, align: end)
    }
    for t in ["0.01%", "0.1%", "1%", "10%", "100%"] { label(X(index - 4), h - 14, t, size: 11, color: muted, align: center) }
    let xs = data.sweep.map(k => X(lx(k)))
    poly(xs, ppvs.map(Y), color: danger, width: 3)
    poly(xs, fns.map(Y), color: accent, width: 2)
    let lp = Math.log10(prev)
    line(X(lp), 14, X(lp), h - 34, color: fade(ink, 0.3), width: 1.5)
    circle(X(lp), Y(post), 7, fill: danger)
    circle(X(lp), Y(negAfter), 5, fill: accent)
    label(X(lp) - 12, Y(post) - 14, "{round(post * 100, 1)}%", size: 12, color: danger, align: end)
  }
}
row(fit: true) {
  badge("chance a positive is sick", tone: danger)
  badge("chance a negative is sick (missed)", tone: accent)
  text("  the line: your prevalence, {round(prev * 100, 1)}%", size: sm, color: muted)
}

grid(columns: 3) {
  stat("Positive → sick", round(post * 100, 1), unit: "%", tone: danger)
  stat("Negative → still sick", negAfter < 0.0001 ? "<0.01" : round(negAfter * 100, 2), unit: "%", tone: accent)
  stat("Prevalence where a positive is a coin flip", round((1 - spec) / (sens + 1 - spec) * 100, 2), unit: "%")
}
```

Drag the specificity up from 99% to 99.9% and watch the red curve shift left by a
factor of ten: for screening a rare condition, the false-positive rate matters far more
than catching every case. A positive is a coin flip exactly where the prevalence equals
(1 − specificity) / (sensitivity + 1 − specificity), about 1% for a 99/99 test.

## What you just saw

- **Accuracy is not the answer.** "99% accurate" describes the test; the chance that
  *you* are sick also depends on how common the condition is among people like you.
- **Count people, not percentages.** Of 1,000 people with a 1% condition, about 10 are
  sick and test positive, and about 10 healthy people test positive too. Half the
  positives are false.
- **Bayes' theorem** is that count written as a formula: P(sick | +) = sick positives
  / all positives.
- **Evidence accumulates.** The posterior after one test is the prior for the next; two
  independent positives make it close to certain, and one negative undoes a lot.
- **Who is tested matters** as much as the test. Low prevalence plus imperfect
  specificity means many false alarms.
